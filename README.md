## Web de lectura

La carpeta `site/` contiene una web estática con las 33 páginas, navegación por tema, progreso de lectura e impresión por página. [Guía para publicarla en Vercel](WEB.md).

La configuración `vercel.json` permite importar este repositorio en Vercel con la carpeta de salida `site`, sin dependencias ni build remoto. El despliegue en Vercel está pendiente porque la herramienta conectada de despliegue respondió `Tool deploy_to_vercel not found`.

La primera entrega desarrolla **Preprocesamiento de datos para aprendizaje no supervisado**, a partir del material de la Maestría en Data Science FIEECS-UNI proporcionado por Diego. Incluye explicación, tres historias inmobiliarias por slide, pregunta de aplicación, transcripción editable y notas del docente.

Los ejemplos utilizan cifras sintéticas y contextos de trabajo inmobiliario. No representan resultados medidos de Cygnus.

## Ubicación de las páginas

Las páginas de lectura están versionadas en la carpeta `wiki/`. La pestaña Wiki nativa de GitHub usa un repositorio separado y todavía no se ha publicado allí esta entrega.
