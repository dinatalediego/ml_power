# Clase 01 · Preprocesamiento de datos para aprendizaje no supervisado

**33 diapositivas, 33 páginas y 99 historias inmobiliarias.** Basado en el PPTX entregado, incluyendo las notas de Kevin Fernandez, Maestría en Data Science, FIEECS-UNI.

Cada página explica la idea, cuenta tres situaciones con problema, decisión y aprendizaje, y termina con una pregunta para aplicarla a CRM, BI o pricing. Las cifras son sintéticas y no provienen de una consulta al data warehouse de Cygnus. No se incluyen datos personales, ventas reales ni resultados empresariales verificados.

Las diapositivas de portada, temario y transición también tienen su propia página. Lee en orden con Anterior/Siguiente, o entra directamente al concepto que necesitas. La transcripción y las notas permiten contrastar el desarrollo con el material de clase.
